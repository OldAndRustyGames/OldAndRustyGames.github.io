# Old & Rusty — Independent Game Studio

> "Hi, I'm an indie game developer. I believe everyone should be able to enjoy games regardless of whether they have a newer system or an older system."

Welcome to the official web repository and legal hub for **Old & Rusty**, an independent studio developing lightweight, high-performance physics and logic games for mobile devices.

### Our Studio Standards

1. **Built for New & Older Hardware:** Engineered with Zero-GC object pooling, strict delta-time clamping, and lightweight canvas/native rendering for smooth 60 FPS gameplay on low-end and older Android devices.
2. **Fair-Play Monetization:** Zero forced interstitial pop-ups. Active gameplay canvases remain clean and unobstructed, and video ads are 100% player-initiated opt-in rewards.
3. **Offline-First & Private:** Zero external tracking servers, zero analytics bloat, and zero account sign-ups required.
